# 摄像头监控系统 - 人脸识别与扩展方案

> 版本：v1.0 | 日期：2026-08-16

---

## 一、概述

当前系统已实现摄像头画面采集、多画面布局、运动检测、人脸检测（Haar Cascade，仅画框）、水印叠加、录像存储等基础功能。本文档旨在规划**人脸识别升级**（从检测到识别）以及**后续扩展方向**。

---

## 二、人脸识别实施方案

### 2.1 当前状态 vs 目标

| 维度 | 当前 | 目标 |
|------|------|------|
| 人脸检测 | Haar Cascade | RetinaFace (ONNX) |
| 人脸识别 | 无（仅标 "Face"） | 识别姓名/会员号 |
| 运行环境 | 仅 CPU | 支持 CPU / GPU (DirectML) |
| 人脸库 | 无 | SQLite 特征库 |
| 注册界面 | 无 | 拍照录入+姓名/会员号 |

### 2.2 技术选型

| 组件 | 推荐方案 | 说明 |
|------|---------|------|
| 人脸检测 | **RetinaFace** (ONNX) | 替换 Haar Cascade，精度大幅提升，支持侧脸/遮挡/口罩 |
| 特征提取 | **ArcFace** (ONNX) | 输出 512 维特征向量，离线运行，无需联网 |
| 特征存储 | **SQLite** | 存储人脸特征向量 + 关联信息 |
| 匹配引擎 | 余弦相似度 + 阈值过滤 | Top-1 匹配，置信度 > 0.6 才识别成功 |
| ONNX 推理 | **Microsoft.ML.OnnxRuntime** | 跨平台，支持 DirectML GPU 加速 |

### 2.4 数据库设计 (SQLite)

```sql
-- 人员表
CREATE TABLE known_persons (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,              -- 姓名
    member_id TEXT,                  -- 会员号
    group_name TEXT,                 -- 分组（员工/会员/黑名单）
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    photo_path TEXT                  -- 注册照片路径
);

-- 人脸特征表
CREATE TABLE face_features (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    person_id INTEGER NOT NULL,      -- 关联 known_persons
    feature BLOB NOT NULL,           -- 512维 float32 特征向量
    quality REAL,                    -- 图像质量评分
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (person_id) REFERENCES known_persons(id) ON DELETE CASCADE
);

-- 识别日志表
CREATE TABLE recognition_logs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    camera_id INTEGER,
    person_id INTEGER,               -- NULL = 未识别
    confidence REAL,                 -- 匹配置信度
    snapshot_path TEXT,              -- 抓拍截图
    recognized_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_face_features_person ON face_features(person_id);
CREATE INDEX idx_recognition_logs_time ON recognition_logs(recognized_at);
CREATE INDEX idx_recognition_logs_person ON recognition_logs(person_id);
```

### 2.7 核心代码示例

#### ArcFace 特征提取

```csharp
using Microsoft.ML.OnnxRuntime;
using Microsoft.ML.OnnxRuntime.Tensors;

public class ArcFaceFeatureExtractor : IDisposable
{
    private readonly InferenceSession _session;

    public ArcFaceFeatureExtractor(string modelPath)
    {
        _session = new InferenceSession(modelPath);
    }

    public float[] ExtractFeature(Mat alignedFace)
    {
        // 预处理：resize 到 112×112, BGR→RGB, 归一化
        Cv2.Resize(alignedFace, alignedFace, new OpenCvSharp.Size(112, 112));
        using var rgbMat = new Mat();
        Cv2.CvtColor(alignedFace, rgbMat, ColorConversionCodes.BGR2RGB);

        var inputData = new float[3 * 112 * 112];
        var index = 0;
        for (int y = 0; y < 112; y++)
            for (int x = 0; x < 112; x++)
            {
                var pixel = rgbMat.At<Vec3b>(y, x);
                inputData[index] = (pixel.Item2 - 127.5f) / 127.5f;      // R
                inputData[index + 112 * 112] = (pixel.Item1 - 127.5f) / 127.5f; // G
                inputData[index + 2 * 112 * 112] = (pixel.Item0 - 127.5f) / 127.5f; // B
                index++;
            }

        var tensor = new DenseTensor<float>(inputData, new[] { 1, 3, 112, 112 });
        var inputs = new[] { NamedOnnxValue.CreateFromTensor("input", tensor) };

        using var results = _session.Run(inputs);
        var embedding = results.First().AsTensor<float>();
        return embedding.ToArray();  // 512维特征向量
    }

    public void Dispose() => _session?.Dispose();
}
```

#### 余弦相似度匹配

```csharp
public static class FaceMatcher
{
    private const float MatchThreshold = 0.6f;

    public static (KnownPerson? Person, float Confidence) Match(
        float[] queryFeature, List<(KnownPerson Person, float[] Feature)> gallery)
    {
        float bestScore = 0;
        KnownPerson? bestPerson = null;

        foreach (var (person, feature) in gallery)
        {
            var score = CosineSimilarity(queryFeature, feature);
            if (score > bestScore)
            {
                bestScore = score;
                bestPerson = person;
            }
        }

        return bestScore >= MatchThreshold
            ? (bestPerson, bestScore)
            : (null, bestScore);
    }

    private static float CosineSimilarity(float[] a, float[] b)
    {
        float dot = 0, normA = 0, normB = 0;
        for (int i = 0; i < a.Length; i++)
        {
            dot += a[i] * b[i];
            normA += a[i] * a[i];
            normB += b[i] * b[i];
        }
        return dot / (MathF.Sqrt(normA) * MathF.Sqrt(normB));
    }
}
```

```
               → 注册成功提示
```
